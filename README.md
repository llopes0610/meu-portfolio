# Portfólio — Lucas Silva Lopes

Portfólio profissional atualizado com React, Vite, Tailwind CSS, Framer Motion e Lucide React.

## Executar localmente

```bash
npm install
npm run dev
```

## Validar antes do deploy

```bash
npm run lint
npm run build
```

## Arquivos que precisam ser mantidos em `public/`

- `Curriculo_Lucas_Silva_Lopes.docx`
- `lucas-perfil.jpg` — adicione sua foto profissional com esse nome.
